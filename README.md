# AudioLab // Spectrum, Sub-Bass & SoundCloud Proxy

Веб-анализатор аудиоспектра в реальном времени с отдельной высокоточной шкалой суббаса (`1 – 80 Гц`), встроенным 7-полосным DSP-эквалайзером и локальным прокси-сервером на **Rust** для поиска и стриминга треков из **SoundCloud**.

## Основные возможности

* **Двойной анализатор спектра (Web Audio API):**
  * Полный логарифмический спектр (`20 Гц – 20 кГц`) с определением пиковой частоты.
  * Детализированная линейная шкала суббаса (`1 – 80 Гц`) с динамической неоновой индикацией уровня удара.
* **Встроенный DSP-эквалайзер:** 7 полос (`Preamp`, `34 Гц`, `60 Гц`, `150 Гц`, `1 кГц`, `4 кГц`, `12 кГц`) на базе `BiquadFilterNode` с быстрыми пресетами.
* **Поиск и стриминг SoundCloud:** Локальный сервер на Rust (`tiny_http` + `yt-dlp`) обходит ограничения CORS, кэширует результаты поиска и проксирует аудиопоток напрямую в браузер.
* **Дополнительные инструменты:** Загрузка локальных аудиофайлов (`MP3`, `M4A`, `FLAC`, `WAV`), захват микрофона без шумоподавления и генератор синусоидального сигнала (`15 – 200 Гц`).

## Стек технологий

* **Backend:** Rust (`tiny_http`, `serde_json`, `ureq`) + `yt-dlp`
* **Frontend:** Vanilla HTML5 / CSS3 / JavaScript (Canvas 2D + Web Audio API)

## Быстрый старт

1. Установите [Rust (Cargo)](https://rustup.rs).
2. Скачайте актуальный бинарник **`yt-dlp.exe`** из [официального репозитория yt-dlp](https://github.com) и положите его в корень проекта (рядом с `Cargo.toml`).
3. Поместите файл `index.html` в папку `C:\dsa\index.html` (или укажите свой путь в `src/main.rs`).
4. Соберите и запустите сервер:
   ```bash
   cargo run --release
   ```
5. Откройте в браузере адрес **`http://127.0.0.1:8080`**.
